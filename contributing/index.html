Contributing

We are using a custom checkstyle configuration file which is based on google's one. It is advisable to use one of the google style configuration files in IDEs to reduce the friction with checkstyle and automate styling.

Building

Pre-requisites

  • jdk 1.8+
  • maven 3.3+

Build

To build the plugin and run all tests just run mvn clean verify

Installation

To use the plugin, install it (by copying the jar from target folder) in lib/ext/ folder of the JMeter installation.

Run JMeter and check the new Siebel HTTP(S) Test Script Recorder is available.
